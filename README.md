# ЭКО SMART қала Алматы

Ғылыми жобаға арналған интерактивті сайт. Жобада қоқыс сұрыпталып, тапсырылады. Одан жиналған қаражатқа қазақи нақыштағы, табиғатқа зиянсыз, ақылды (SMART) жаңа эко қала салу ұсынылады.

## Жобаның идеясы

1. **Сұрыпта:** қалдықтарды түріне қарай бөлеміз (пластик, қағаз, шыны, металл).
2. **Тапсыр:** SMART қабылдау автоматы қалдықты таниды, өлшейді және бонус береді.
3. **Қор жина:** сатылған шикізаттан түскен ақша «Эко-қорға» түседі.
4. **Сал:** қазақи нақыштағы эко ғимараттар, саябақ және жасыл көлік саламыз.

Қаланың ғимараттары ұлттық символдарға негізделген: шаңырақ, тұмар, домбыра, бесік, тайқазан. Әр ғимарат төрт көзқараспен түсіндіріледі: **сәулетші**, **дизайнер**, **эколог** және **өнертапқыш**.

## Сайттың бөлімдері

- **Жоба идеясы:** мақсаты мен жұмыс кезеңдері.
- **3D қала:** қаланы айналдырып қарауға болады. 2026–2036 жылдар бойынша қаланың қалай салынатыны көрсетіледі.
- **Ғимараттар:** «Бесік» балабақшасы, «Тайқазан» эко базары, «Шаңырақ» орталығы, «Тұмар» мұнарасы және т.б.
- **Материалдар кестесі:** қайта өңделген материалдар, олардың болжамды бағасы мен экологиялық пайдасы.
- **Экономикалық есеп:** қаражатты есептейтін калькулятор.
- **Экологиялық және экономикалық тиімділік.**
- **SMART өнертабыстар:** мысалы, ЖИ-жәшік «Сұрыпшы».

## Технология

- Бір ғана `index.html` файлы. Ішінде HTML, CSS және JavaScript бар.
- Оқушының суреті файлдың ішіне (base64 түрінде) салынған, сондықтан бөлек сурет файлы керек емес.
- Қаріптер: Google Fonts (Montserrat, Unbounded).
- Сыртқы кітапханалар мен құрастыру (build) қажет емес.

## Іске қосу

**Компьютерде:** `index.html` файлын браузерде ашсаңыз жеткілікті.

**Vercel-ге жариялау:**
1. Жоба папкасындағы ескі `index.html`-ді жаңасымен ауыстырыңыз.
2. GitHub арқылы қосылған болса, өзгерісті commit/push жасаңыз. Vercel өзі қайта жариялайды.
3. Немесе терминалда: `vercel --prod`
